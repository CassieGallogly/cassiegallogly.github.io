Gesture-Controlled Game

UC Santa Cruz · Embedded Systems

Overview

Built a Simon Says-inspired game controlled through a sensor glove. Five flex sensors, an IMU and a vibration motor connect to an STM32 programmed in C. Gestures are recognized and used to control a Python Turtle game in real time.

My work

Embedded C, STM32, Python, sensors, IMU integration and human-computer interaction.

Project focus

The glove recognizes multiple hand shapes and orientations, translating hand motion into gameplay.
